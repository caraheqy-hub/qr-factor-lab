# 因子失败复盘与评价流程 v2（2026-10-04）

## 为什么迄今没有“可用”因子

1. **预测关系不稳定**：方正“球队硬币”沪深300适配版 2020—2024 逐年月均 IC 为负，2025 近零且翻转；低总资产增长率 2020—2023 月均 IC +0.048、2024—2025 −0.018、2026 已见 −0.070。后两段的均值变化是预定门槛失败，不能据此证明真实效应必定为负。
2. **排序信号不等于多头收益**：国君 Alpha5 原式正 IC，却在 2021、2025 连零费用前 20% 毛超额也为负；12 组平滑/持有期/宽度组合在 2020—2023 发现期按 15 基点/单位换手扣费后均值均负。头部收益、分组单调性及换手比 IC 更贴近本项目的多头目标。
3. **来源迁移有口径差**：方正原研报翻转阈值用全 A 股截面，本项目只用了当时沪深300；可转债现金流质量指标被迁移到股票。原文绩效不能充当这些适配版的独立证据。
4. **历史组合仍偏乐观**：若入选股未来价缺失，一些脚本跳过整期、重置仓位；涨跌停/停牌常仅统计次数，未维持未成交仓位；部分费用未按漂移后权重计算。指数退出股票的后续价格也不完整。此类结果可淘汰明显较差候选，不能证明真实可成交净收益。
5. **历史已见且试验多**：2020—2026 的结果已反复查看；改变参数、方向或筛选条件再看同一时期，会扩大选择偏差。因子研究存在多重检验问题，参见 [Harvey、Liu、Zhu](https://www.nber.org/papers/w20592) 与 [Bailey 等](https://papers.ssrn.com/sol3/Papers.cfm?abstract_id=2326253)。真正独立确认须冻结设计后等待新增时段。

## 现有判定手段哪里合适，哪里不足

| 手段 | 合适用途 | 不能推断的事 / 修正 |
| --- | --- | --- |
| PIT 来源、时点、历史成分核验 | 硬性数据门槛 | `pub_date`、复权和历史成分仍需抽样核实修订语义；源公式与本地适配分开写 |
| Rank IC、覆盖、正值月份 | 快速淘汰、发现符号翻转 | 小的正 IC 并不保证头部组合盈利；固定“每年正 IC”是保守筛查条件，不是统计充分必要条件；报告分组、效应大小和按月自相关稳健区间 |
| 统一 15 基点成本筛查 | 候选费用敏感性的一档 | 费用不是已校准的实际成交成本；报告 5/10/15/25 基点曲线、换手及盈亏平衡费用，不能把 5 日与月度每期基点直接比较 |
| 当前组合收益 | 乐观上界或失败诊断 | 缺价跳期、成分退出、涨跌停和仓位漂移会产生选择偏差；必须用不跳期的持仓状态机与同日同可投集合基准重算 |
| 2024—2026 分段结果 | 已见时期的压力检查 | 已影响研究决定，不能再称盲测；新增数据必须按冻结设计前向评估 |

因而现有顺序适合**筛查和拒绝**，尚不足以**确认可用**。将结果明确分成：`E0 数据/公式未核实`、`E1 信号探索`、`E2 乐观扣费诊断`、`E3 完整历史成交模拟`、`E4 冻结后前向验证`。只有 E3 和 E4 共同通过、且相对同池基准有净增量，才考虑“可用”表述；当前没有 E3/E4 证据。

[已见月度 IC 的不确定性审计](../results/method_audit/ic_uncertainty.csv)固定 Newey–West 3 个月滞后，只作事后描述、未校正多重试验。低总资产增长率发现期的正均值近似 95% 区间为 `[+0.004,+0.093]`，2024—2025 为 `[−0.057,+0.021]`；后段未通过预定方向门槛，却也不能据此断言真实 IC 必为负。方正“球队硬币”20 日适配版发现期约 `[−0.123,−0.050]`，2024—2025 约 `[−0.114,+0.027]`。这些区间不能修复来源股票池差异或成交缺口。

## 更深入但受控的调参

1. 先写因子卡：原式及方向、机制、字段/单位、股票池、信号与成交时点、缺失与停牌规则。分开记录**公式参数**（窗口/平滑）和**策略参数**（持有期/组合宽度/成本）。预登记少量邻近参数和预期机制，记下全部失败项。
2. 各候选用相同信号日、相同可投股票和相同前向收益；窗口不同造成的起始样本差异要取交集或单列。先做覆盖、分组、IC 与简单因子/规模/行业暴露对照，再做策略。入选后因未来无法交易而缺价的股票应进入持仓状态处理，不能删除整期。
3. 在发现期的滚动时间切分中选参数：训练窗口只用过去，验证窗口与最长标签/持有期之间留隔离带；预先固定候选数、主要目标为**同池同日基准的净超额**，并约束覆盖、交易失败率、最差年份与容量。选相邻参数都尚可的平坦区域，不选单点最高 IC 或 Sharpe。逐个保存所有窗口及方向、费用敏感性和淘汰理由。
4. 选定后冻结公式、方向、参数、执行状态机与成本档，做一次已见压力检验；任何根据该段结果修订都要记为新试验，原段随即降级为已见。多次试验下的显著性须计入试验总数，并用按月区块重采样或自相关稳健区间表达不确定性；单个正均值不够。
5. 最后在 2026-10 以后真正新增数据按冻结代码前向运行，分别报告净超额、成交失败、容量和相对简单基准的增量。当前数据不能替代这一步。

## 统一试验账本

使用 [`trial_store.py`](trial_store.py)：

```powershell
python research\trial_store.py refresh
python research\trial_store.py run research\screen_asset_growth.py
python research\trial_store.py run research\tune_gtja_alpha5.py
```

- `results/trial_store/records.jsonl`：已迁入的结构化结果，每行有稳定 `trial_id`、参数、样本、指标及单位、证据等级、原 CSV/JSON 行号或条目序号、文件哈希和可用的来源元数据。已迁入 **42 个结果文件、5,470 条记录**；`historical_execution_verified=false` 明确标出旧组合未达成交验证级别。
- `sources.jsonl`：所索引结果文件及 SHA256；文本哈希先将 CRLF 规范为 LF，跨平台一致。`excluded.jsonl` 列出 12 个逐日明细/已有汇总的月度 IC 文件及排除理由，便于核对是否漏掉结果。`run_history.jsonl`：使用 `run` 命令以后每次运行的时间、脚本哈希、Git 提交、退出码及变更文件；派生 CSV/JSON 另按内容哈希留在 `artifact_snapshots/`，避免覆盖后丢失。历史运行时刻不能从旧汇总文件可靠重建，因此不伪造。
- 旧版多种输出口径仍在；统一账本保留原列名与单位提示，**不把不同持有期的每期基点或不同股票池的结果强行合并成一个排名**。未来实验都用 `run` 入口并检查其记录；仅运行原脚本不会产生运行事件。
